COMPUTE ENGINE (MYSQL (MARIADB) ON LINUX (DEBIAN)
=========================================================================================================
1. Create a project
	---- either from firebase or gcp console
2. Compute Engine (for MySql)
	REFERENCES
	*** https://medium.com/codex/full-guide-install-mysql-phpmyadmin-on-google-cloud-compute-engine-vm-7e31d3f0d968
	*** https://docs.cloud.google.com/compute/docs/instances/mysql/discover-mysql
	STEPS
	--- make sure the correct project is selected
	--- enable compute engine service
	--- create a VM instance
		a. Machine Configuration
		--- intance-pt-1
		--- asia-southeast1
		--- machine type - e2
				 - e2-micro (2 vCPU, 1 core, 1GB Memory)
		b. OS and Storage
		--- Debian GNU/Linux 12
		c. Data Protection
		---  No Backups
		d. Networking
		--- DO NOT ALLOW Http/Https (its NOT for public, only for our Django App from App Engine)
		--- Network Tags: mysql-pt-1
		--- Hostname: (Leave blank)
		--- IP Forwarding: (Keep off)
		--- Network Interfaces: nic0 default IPv4 (10.148.0.0/20) - internal IP on the server
		e. Observability
		--- Ops Agent (Disable it)
		f. Security
		--- Service Account (just accept default)
		--- Access Scopes : Allow default access
		--- Shielded VM
			--- Turn on Secure Boot (Disabled)
			--- Turn on VTPM (Enable)
			--- Turn on Integrity Monitoring (Enable)

		--- Manage Access
			--- Everyhing leave as the default
		g.Advanced
		--- Enable Delete protection (Enable)
		--- Reservations: Dont use reservations
		--- Data Encryption: Google managed encryption keys
	--- CREATE

	Go to the list of VM instances, select the newly created instance ("instance-pt-1")
	--- select edit
	--- Under Networking Interfaces
		--- select the default nic0
			--- Alias IP Ranges
			--- Select Ephemeral (THIS WILL RESULT IN EXTERNAL CHANGING ON EVERY START)
				**** IF SELECTED THE BELOW, STATIC IP ARE CHARGEABLE
				--- Click "Reserve static external Ip Address"
				--- name: instance-pt-1-external-ip
				--- Click Reserve
					--- External IP: 34.158.40.16 (auto generated)
