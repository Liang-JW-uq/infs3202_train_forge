1. mkdir pt_trainer

B. Setup git repository
============================================================
1. Login to GitHub
    --- create a new repository (pt_trainer)
2. Create new python project
    --- mkdir pt_trainer
3. Create .gitignore
4. CMD: git init
5. CMD: git remote add origin https://github.com/royliangsehhaw7/pt_trainer.git
    --- the project url is from github.com repository SSH link in the main repository page
6. CMD: git remote -v
    --- this is to check if git connection is made
7. CMD: git branch --show-current
    --- showing current branch you are working on (since its new, should be master)
8. CMD: git branch -m main
    --- creates a new branch "main"     (???NOT SURE WHY CREATE A NEW BRANCH MAIN INSTEAD OF USING MASTER BRANCH???)

Check in new or amended files
-----------------------------
9. CMD: git status
    --- show all files changes,additions,deletions
    --- RED are pending 'add'
    --- GREE are pending 'commit'
9. CMD: git add .               (add all)
10 CMD: git commit -m "<<remarks">>
11.CMD: git push -u origin main     (or just git push if the you are sure of currrent branch and origin has already been setup properle)
        --- firstly, check what is the current branch using "git branch --show-current" (should be main)

NOTE: for renaming of files, might have to run again these after pushing
      CMD: git add .
      CMD: git commit -m "<<remarks>>"
      CMD: git push


NOW TO CREATE NEW BRANCH TO START MODFICATIONS
-----------------------------------------------
THe initial (main) branch is suppose to be the 'production' or final, will merge any changes in new branch to main later
CMD: git checkout -b <<branch name>>    
    --- this will create AND switch to new branch
CMD: git checkout <<branch name>>
    --- this is to switch only (no create)

CMD: git branch
    --- check all available branches for the current repository
CMD: git branch -m <<new-name>>
    --- renames a branch

Merging (RMB: its merging from)
CMD: git checkout main 
    --- switch to the target merge branch first
CMD: git merge <<branch-to-merge-from>>
    --- then specify the branch to merge from
